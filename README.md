# Potion landing

Static landing page for Potion (potionalpha.com), rebuilt in night and violet.

- `index.html`: the page, one file, English.
- `assets/css/potion.css`: styles. Bricolage Grotesque for titles and numbers, Inter for the rest.
- `assets/js/potion.js`: cursor, hero, performance counters, the four process scenes, results, pricing.
- `assets/img`: the real performance charts, member avatars and the Potion mark.

GSAP is loaded from cdnjs; without it the page still renders with every state posed.

Open `index.html` in a browser, or serve the folder with any static server.
